# Going Vegan : the Numbers

This app is live on streamlit at : https://ychv-going-vegan-the-numbers-dataviz-project--app-fqpcbj.streamlit.app/

If you wish to lauch it locally, make sure you have the proper packages using 
```
pip install -r requirements.txt
```
and then running the command
```
streamlit run app.py
```
